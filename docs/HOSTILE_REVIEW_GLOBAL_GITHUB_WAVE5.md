# Hostile review — Global GitHub ingestion Wave 5 / deep lane

Exact evidence: `state/global-github/DEEP_DIVE_2026-09-29_V4.json`.

> **Challenge: A belief state can become a sophisticated way to preserve a wrong world model.**

Accepted. Partial observability does not excuse model lock-in. Beliefs remain hypotheses constrained by observations, rival models, and explicit falsifiers. The transfer is observation != latent state, not "trust the belief model."

> **Challenge: Robot real-time control architecture is not a general template for human-scale reasoning.**

Accepted. Only the separation of command, observed state, lifecycle/resource availability, and timing is transferred. Real-time scheduling parameters and ROS-specific mechanics are not generalized.

> **Challenge: A fresh search index can return fresh nonsense.**

Accepted. Retrieval currentness and source truth are independent dimensions. Refreshing a reader improves temporal visibility, not evidence quality.

> **Challenge: R-hat, ESS, divergences and chain counts are domain-specific MCMC diagnostics.**

Accepted. The transfer is narrower: repeated outputs can be correlated or generated by a failing process, so output count is not independent evidence. PyMC thresholds are not transplanted into language-model reasoning.

> **Challenge: Exact version identity can create false confidence if the version itself was bad.**

Accepted. Version binding provides reproducibility/provenance, not correctness. Evidence quality remains separate.

> **Challenge: Wave 5 is still curated and query-biased.**

Accepted. It adds 80 non-overlapping repositories but does not make the corpus representative of GitHub. Coverage metrics remain sampled-corpus metrics.

## Disposition

All five patterns survive only as bounded operating disciplines. No code is copied, no domain implementation is adopted by implication, and none changes the model-weight or AGI claim ceiling.
